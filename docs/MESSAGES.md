# Прототипы сообщений Gatecheck Bot — дизайн-спека

> **Статус:** прототип v1 для v0.10 (по фидбеку с прода, 2026-09-13). Код ещё НЕ переписан —
> правки текстов делаются ЗДЕСЬ, подтверждаемые пользователем, и только потом переносятся в код.
> **Источник требований:** фидбек первого боевого дня (Gulmorogod, 17 киллов на Amamake-гейте).

## 0. Общие правила оформления (действуют на все сообщения)

1. **HTML parse mode** (нужен для `<blockquote expandable>`); все данные экранируются.
2. **Все команды в текстах — с нижним подчёркиванием**: `/zone_status`, `/zone_on`, `/zone_off`,
   `/route_status`, `/route_stop`. Telegram делает их кликабельными ссылками; пробел внутри
   команды разрывает ссылку (причина замены). Старые формы с пробелом поддерживаются кодом
   для совместимости, но в текстах — только подчёркивания.
3. **Время в футерах — EVE Time (ET)** = UTC+0, формат `HH:MM`.
4. **Footer всех зональных репортов:**
   `Статистика за последний час. Запрос репорта по /zone_status. Местное время - HH:MM ET`
5. **Заголовок камп-репортов:** «Сейчас гайки кемпят в системе:» / «Сейчас гайки кемпят в системах:»
   (по числу систем с активностью). Единообразно для алертов, /zone_status и кнопки обновления.
6. **Блок системы = `<blockquote expandable>`** — свёрнут; до раскрытия видна только первая
   строка «В {система} N килов и {ISK} на гейтах» — по одному взгляду понятен масштаб боя.
7. **Десятиминутные киллы удалены полностью** (zK API отдаёт киллы с задержкой — 10-минутное
   окно всегда пустое). Все счётчики — **за последний час**. Триггеры D5:
   - накопление ≥ {hour} киллов на гейтах системы за час (дефолт 8, границы 4…20);
   - ценность: droppable ISK на гейтах системы за час ≥ {isk} (дефолт **0.5B**, границы 10M…5B).
8. Ссылки на zKillboard убраны (превью zK спамило чат). «Причина:» убрана — только конкретика.
9. **Анти-спам:** повторный репорт по системе — только при НОВЫХ киллах с прошлого репорта
   (+ cooldown 15 мин на систему, настраивается).

## 1. Алерт зоны — одна система (пуш)

```text
Сейчас гайки кемпят в системе:

<blockquote expandable>В Gulmorogod 21 килл и 1.2B ISK на гейтах

на Egmar: 4 за час (+4 от прошлого репорта), droppable 300M
атака: коллективный кемп · корабли: Caracal ×2, Maller, Capsule

на Amamake: 17 за час (+13 от прошлого репорта), droppable 900M
атака: соло · корабли: Tengu</blockquote>

Статистика за последний час. Запрос репорта по /zone_status. Местное время - 18:42 ET
```

Правила блока системы:
- **Первая строка** (видна без раскрытия): `В {система} {N} килов и {ISK} на гейтах`,
  где N — суммарные киллы на гейтах системы за час, ISK — сумма droppable за час по гейтам.
- **Каждый «горящий» гейт** (с киллами за час), через пустую строку:
  - `на {система-назначения}: {N} за час ({±N от прошлого репорта}), droppable {ISK}`;
    вместо `Stargate (Amamake)` — просто **«на Amamake»** (контекст гейта очевиден);
  - ниже — линия атаки: `атака: {соло | коллективный кемп | соло + групповые} · корабли: {список}`;
    состав атакующих — уникальные типы кораблей атакующих за час на гейте, «Имя ×N»;
  - гейты без киллов за час **не перечисляются** (не «горят»).
- **Дельта `({±N})`:** разница с ПРОШЛЫМ репортом этого чата по этому гейту (алерт или
  /zone_status — оба обновляют «прошлый репорт»). Первый репорт по гейту — без скобок.
- **Плюрализация киллов:** 1 килл · 2–4 килла · 5+ киллов.
- NPC-киллы (zkb.npc) учитываются в счётчике, но не считаются атакой игроков — линия
  атаки для чисто-NPC гейта: `атака: NPC`.

## 2. Алерт зоны — несколько систем (один пуш)

```text
Сейчас гайки кемпят в системах:

<blockquote expandable>В Gulmorogod 21 килл и 1.2B ISK на гейтах
…(как выше)…</blockquote>

<blockquote expandable>В Siseide 3 килла и 50M ISK на гейтах

на Vard: 3 за час (+3 от прошлого репорта), droppable 50M
атака: соло · корабли: Rifter</blockquote>

Статистика за последний час. Запрос репорта по /zone_status. Местное время - 18:42 ET
```

Все сработавшие системы — в одном сообщении, блоки через пустую строку.

---

## 3. /zone_status — с активной подпиской

То же самое (немедленный тик не выполняется — данные из накопленных событий; для свежести —
кнопка «🔄 Гейты: обновить»), плюс строка про чистые системы:

```text
Сейчас гайки кемпят в системах:

<blockquote expandable>…(блоки активных систем, как в §1)…</blockquote>

✅ Чисто: 10 систем
Статистика за последний час. Запрос репорта по /zone_status. Местное время - 18:42 ET
```

Если активных систем нет:

```text
Сейчас гайки в зоне не кемпят.

✅ Чисто: 13 систем
Статистика за последний час. Запрос репорта по /zone_status. Местное время - 18:42 ET
```

---

## 4. /zone_status — без подписки (разовый живой опрос)

Тот же формат (заголовок + блоки + footer), но данные — разовый опрос zK прямо сейчас,
после footer добавляется строка `Постоянное слежение: /zone_on`. Если чисто:

```text
Сейчас гайки в зоне не кемпят.

✅ Чисто: 13 систем
Постоянное слежение: /zone_on
```

---

## 5. Кнопка «🔄 Гейты: обновить» — отчёт по зонам

Немедленный тик зональных слежек чата (алерты по новым киллам придут как обычно), затем
**отчёт** — тот же формат §3 (заголовок «Сейчас гайки кемпят…», блоки, footer). Обновляет
**только мониторинг активных зон** (маршрут — отдельная сущность со своим статусом).

## 6. Алерт маршрута

Заголовок лаконичный, блок — в том же quote-формате (пер-гейт, без «Stargate()»):

```text
🚨 Гейт-камп на маршруте (точка 3/16):

<blockquote expandable>В Beta 1 килл и 500M ISK на гейтах

на Gamma: 1 за час (+1 от прошлого репорта), droppable 500M
атака: коллективный кемп · корабли: Maller</blockquote>

Статистика за последний час. Остановить слежение: /route_stop. Местное время - 19:05 ET
```

---

## 7. /route_status — активный маршрут

```text
🛡 Слежение маршрута Amamake → Jita — осталось 42 мин.

Сейчас гайки на маршруте не кемпят.
Точек проверено за час: 16.
Статистика за последний час. Остановить слежение: /route_stop. Местное время - 18:42 ET
```

При активности — блоки систем маршрута в том же quote-формате (заголовок
«Сейчас гайки кемпят на маршруте:»).

## 8. /start

```text
Привет, {имя}! 👋

Gatecheck Bot v0.10.0 — слежение за гейт-кампами EVE Online.
Кнопки меню — под полем ввода: 🔄 Гейты: обновить · Зона · Маршрут · Пороги.

Команды:
• /zone_on — мониторинг зоны «Hed + соседи» (алерты по гейтам)
• /zone_status — разовый отчёт по гейтам зоны
• /route Amamake Jita — маршрут + слежение (TTL 1 ч)
• /help — вся справка

Подписки переживают рестарт бота.
```

## 9. /help

```text
Команды:
/zone_on — включить зону «Hed + соседи» · /zone_off — выключить
/zone_status — отчёт по гейтам зоны (разовый, если нет подписки)
/route {A} {B} — маршрут + слежение (TTL 1 ч)
/route_status — статистика · /route_stop — остановить
/settings — пороги алертов (границы показываются)

Кнопки: 🔄 Гейты: обновить · Зона · Маршрут · Пороги.
Все отчёты — по киллам НА ГЕЙТАХ за последний час.
Версия: v0.10.0.
```

## 10. /settings — пороги D5 (без 10-минутки)

Просмотр (`/settings`):

```text
Пороги зоны (D5), границы:
• hour: 8 киллов на гейтах за час (4…20)
• isk: 0.5B droppable на гейтах за час (10M…5B)
• cooldown: 15 мин (5…60 мин)
• атака в алертах: вкл

Изменить: /settings_hour 10 · /settings_isk 0.7B · /settings_cooldown 20м · /settings_attackers off
Сброс всех: /settings_reset
```

Изменение (`/settings_hour 10`, `/settings_isk 0.7B`, `/settings_cooldown 20м`,
`/settings_attackers off`) — ответ `✅ hour = 10 (действует со следующего /zone_on)`.
Границы: hour 4…20 · isk 10M…5B · cooldown 5…60 мин · attackers on/off.

## 11. /ping — только админ

Админ — текущий ответ (аптайм, статика, слежки, счётчики zK).
**Не-админ — бот молчит** (служебная команда, пользователям не нужна).

---

## 12. Кнопки

**Reply-клавиатура** (под полем ввода, задаётся на /start и /help):

```text
[ 🔄 Гейты: обновить ]
[ 🛡 Зона: вкл ]   [ 🛡 Зона: выкл ]
[ 🚀 Маршрут: статус ]   [ 🚀 Маршрут: стоп ]
[ ⚙️ Пороги ]
```

- «🔄 Гейты: обновить» — немедленный тик зональных слежек + отчёт §3 (обновляет ТОЛЬКО зоны);
  без зональных слежек — разовый опрос (§4).
- Кнопки «Зона: статус» больше нет — функционал полностью покрыт «Гейты: обновить».
- Labels человекочитаемы; обработка — по точному тексту кнопки (F.text == label).

**Inline:** «🔄 Обновить» — только на зональных репортах (§1–§4; callback refresh:zone).
На сообщениях маршрута inline-кнопки нет.

## 13. Ошибки и краевые случаи (тексты)

```text
Не нашёл систему: {name}. Проверь написание (граф — весь Новый Эден, без вормхолов).
Маршрут {A} → {B} не найден (нет гейт-связности).
Граф гейтов ещё не собран: python scripts/fetch_static.py
Слежение не активно. /route {A} {B} — включить.
Зона не включена. /zone_on — включить.
```

## 14. Что нужно для реализации (чек-лист v0.10)

1. **HTML parse mode**: `DefaultBotProperties(parse_mode=ParseMode.HTML)` в aiogram; экранирование.
2. **Удалить 10-минутное окно**: WINDOW_BURST, burst_threshold (триггер-1), «за 10 мин» из текстов;
   в /settings — убрать burst, isk_burst переименовать в isk (семантика «за час»).
3. **Заголовки/footer** по §0 (EVE Time = UTC).
4. **Quote-блоки** по §1–§2 (первая строка + горящие гейты + атака).
5. **Дельта**: SQLite-таблица `report_counts (chat_id, system_id, gate_id, count, updated)` —
   upsert при каждом репорте/статусе; дельта = сейчас − прошлое значение.
6. **Атака**: из киллов (attackers + zkb.solo/npc) — соло/коллективный/смешанный + состав кораблей
   (resolve имён через ESI); настройка `attackers` on/off (users.settings_json, /settings_attackers).
7. **Подчёркивания**: команды /zone_on /zone_off /zone_status /route_status /route_stop
   (+ поддержка старых форм с пробелом), все упоминания в текстах — подчёркиванием.
8. **/ping**: только ADMIN_IDS, остальным — без ответа.
9. **Кнопки**: лейблы §12, F.text-маппинг; убрать кнопку статуса зоны; inline — только на зона-репортах.
10. **/start, /help** по §8–§9.
